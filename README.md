# Analisis Sentimen Aplikasi SimSimi Menggunakan LSTM, SVM, dan Random Forest

## 📌 Deskripsi Proyek

Proyek ini bertujuan untuk membangun sistem analisis sentimen berbasis teks dalam Bahasa Indonesia terhadap ulasan aplikasi SimSimi yang diambil dari Google Playstore. Sistem ini mengklasifikasikan sentimen pengguna menjadi **positif**, **netral**, dan **negatif**. Tujuan utama dari proyek ini adalah membandingkan efektivitas dan akurasi dari ketiga pendekatan tersebut dengan berbagai skema pelatihan.

---

## Dataset

- Berasal dari hasil **scraping** ulasan aplikasi SimSimi di Playstore.
- Total jumlah data: **20.000 data ulasan**.
- Label sentimen: **Positif**, **Netral**, dan **Negatif**.
